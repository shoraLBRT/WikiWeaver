# Pull Request Guidelines

## Language and style
- Write the PR title and description in English.
- Keep the text concise and specific.
- Use short, factual statements and bullet points.
- Do not add agent signatures or footer lines (for example: "Generated by ...").

## Required structure
Use this section order in every PR description:
1. `Summary`
2. `Changes`
3. `Testing`
4. `Risks`
5. `Checklist`

## Template
```md
## Summary
1-3 short sentences about what changed and why.

## Changes
- Key change 1
- Key change 2

## Testing
- `dotnet test` - passed
- Manual check: <what was verified>

## Risks
- Main risk (if none, write: `Low: no known risks`)

## Checklist
- [ ] Scope is focused and does not include unrelated refactors
- [ ] Tests were added/updated or a reason is provided
- [ ] Docs were updated if behavior/contracts changed
- [ ] No secrets or credentials were introduced
```
